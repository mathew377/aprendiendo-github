\# Ejercicio 2: Guardar cambios con commits



\## Objetivo

Registrar cambios en el repositorio y enviarlos a GitHub.



\## Pasos realizados

1\. Creé el archivo `notas.txt` con `touch` y escribí "Mi primer ejercicio en GitHub".

2\. Revisé el estado del repositorio con `git status`.

3\. Preparé los cambios con `git add .`.

4\. Guardé los cambios con `git commit -m "Agrega archivo de notas"`.

5\. Los envié a GitHub con `git push origin main`.

6\. Consulté el historial con `git log`.



\## Comandos utilizados

\- `git status`: muestra el estado de los archivos.

\- `git add .`: prepara los cambios para el commit.

\- `git commit -m`: guarda una fotografía del proyecto con un mensaje.

\- `git push`: sube los commits a GitHub.

\- `git log`: muestra el historial de commits.



\## Conclusión

El ciclo status, add, commit y push es la base del trabajo con Git y permite mantener un historial ordenado de cambios.
