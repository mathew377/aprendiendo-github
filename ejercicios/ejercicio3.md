\# Ejercicio 3: Ramas y Pull Request



\## Objetivo

Trabajar en una rama separada y fusionar los cambios a la rama principal.



\## Pasos realizados

1\. Creé la rama `desarrollo` con `git branch desarrollo`.

2\. Cambié a ella con `git switch desarrollo`.

3\. Realicé un cambio y lo guardé con add y commit.

4\. Volví a la rama principal con `git switch main`.

5\. Fusioné los cambios con `git merge desarrollo`.

6\. Creé la rama `mejora-readme`, la subí a GitHub y abrí un Pull Request.

7\. Revisé los cambios en Files changed y fusioné el Pull Request.



\## Comandos utilizados

\- `git branch`: crea o lista ramas.

\- `git switch`: cambia de rama.

\- `git merge`: fusiona los cambios de una rama en otra.



\## Conclusión

Las ramas permiten trabajar sin afectar la versión principal, y el Pull Request permite revisar los cambios antes de incorporarlos.
