\# Ejercicio 1: Crear y clonar un repositorio



\## Objetivo

Crear un repositorio en GitHub y copiarlo al computador local.



\## Pasos realizados

1\. Ingresé a GitHub y creé un repositorio nuevo llamado `mi-primer-repositorio`, público y con README.

2\. Copié la URL HTTPS del repositorio con el botón Code.

3\. Abrí Git Bash y ejecuté `git clone` con la URL copiada.

4\. Entré a la carpeta con `cd mi-primer-repositorio`.

5\. Verifiqué el contenido con `ls`.



\## Comandos utilizados

\- `git clone`: copia un repositorio remoto al computador local.

\- `cd`: cambia de carpeta.

\- `ls`: lista los archivos de la carpeta.



\## Conclusión

Clonar un repositorio permite trabajar localmente con una copia completa del proyecto y su historial.
